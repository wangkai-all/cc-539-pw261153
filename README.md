# 协议状态机推断工具（DFA 合成与演示）

从一批**只知道最终接受 / 拒绝**的设备操作序列，推断一个可解释的确定性有限状态机（DFA），
并支持候选解释比较与序列单步演示。**纯本地静态页面，不连接任何真实设备。**

## 运行

无需构建、无第三方依赖，直接用浏览器打开 `index.html` 即可（`file://` 可用）；
也可以在本目录起一个静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000/
```

## 目录结构

| 文件 | 职责 |
| --- | --- |
| `js/sat.js` | 自建 DPLL 约束求解器：双监视字面量（槽位方案）、首 UIP 学习、非时序回跳、VSIDS + 相位保存、时间预算 |
| `js/dfa.js` | DFA 求值、可达性、划分求精最小化与规范化签名、乘积状态图 BFS 最短分歧串 |
| `js/synth.js` | 单热路径 SAT 编码、按状态数递增搜索、阻塞子句枚举候选、删除式 UNSAT 核心 |
| `js/app.js` | 录入、求解调度、SVG 状态图、候选比较、单步演示 |
| `tests/test.js` | Node 测试：`node tests/test.js` |

## 模型约定

- 状态 `q0` 为起始状态；最后一个状态是固定的**拒绝汇点**：非接受、所有操作自环。
- 每个操作符号在每个状态下有且仅有一个后继（完整转移表）；“转移缺失”统一落入拒绝汇点。
- 演示状态上限默认 **6**，拒绝汇点计入状态数，可在页面调整。
- **空序列 ε** 允许作为样本，其接受性等于起始状态 `q0` 的接受性。

## 搜索策略与诚实性保证

1. 先检测同一序列被同时标成正例和反例的**直接冲突**，定位冲突样本。
2. 状态数 `n = 1 … 上限` 依次用 SAT 求解：只有某规模被**证明 UNSAT** 才尝试更大规模。
3. **超时不等于无解**：超时只记录，继续后续规模；最终无候选时区分
   “全部证明无解（UNSAT）”与“搜索超时（不能断言无模型）”。
4. 只有所有更小规模都被证明无解，当前模型才标注“**最小性已证明**”；
   否则标注“最小性未证明”。最小性仅针对本状态上限与汇点约定。
5. 上限内证明无解时，用删除法给出一组**无法同时满足的样本核心**，并明确说明
   这只在当前上限 / 约定下成立，不代表任意规模都无解；核心提取本身超时会标注为部分核心。
6. 找到模型后枚举同规模其它赋值，用**规范化签名**（最小化 + BFS 重编号）排除仅由
   状态编号、不可达或等价状态造成的差异；语言相同则不构造不存在的分歧串。
7. 存在语言不同的第二份候选时，在两台 DFA 的**乘积状态图上 BFS** 求最短分歧序列，
   页面可一键把该序列补标为正例 / 反例后重新求解。
8. 区分搜索明确区分三种结论：找到分歧候选 / **已证明穷举结束（无分歧串）** / 枚举超时。
9. 单步演示对未标注序列给出的接受 / 拒绝一律标注为“**模型推断**”，不冒充设备验证。

## 内置本地示例

1. 重复前缀（偶数个 `ab`，含 ε 反例）
2. 空序列是正例（偶数个 `x`）
3. 矛盾标注（同一序列正 + 反，触发冲突定位）
4. 样本不足（存在多份语言不同的候选，给出最短分歧串）
5. 一元鸽链样本（必然需要 7 个总状态，在 6 上限内 UNSAT 并给出冲突核心）
